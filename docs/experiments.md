### 训练曲线说明

DQN 训练过程中记录以下指标（TensorBoard 可视化）：

- **Episode Reward**：每回合累积奖励，期望逐步上升并收敛
- **ε 值**：探索率衰减曲线
- **Loss**：TD 误差，期望逐步下降
- **Average Action Value**：Q 值均值，反映策略稳定性

```

Reward
  ↑
  │                          ___________
  │                     ____/
  │                ____/
  │           ____/
  │      ____/
  │ ____/
  │/
  └──────────────────────────────→ Episode
  0        200       400       ...    1000
```

## 已知局限

1. **数据集语言偏差**：主训练集（SST-2、GoEmotions、RAVDESS）均为英文数据。中文情感识别依赖 CH-SIMS 等较小规模数据集，可能影响中文场景效果。

2. **实验室环境 vs 真实场景**：公开数据集的语音/文本在噪声、语速、口语化程度上与大学生真实使用场景有差距。

3. **DQN 状态空间简化**：当前状态表示未包含对话历史语义、用户长期偏好等深层信息，可能限制策略优化上限。

4. **用户测试周期**：3 个月的用户测试虽能观察短期效果，但难以评估长期黏性和心理健康持续改善。

5. **单模态融合权重**：当前融合策略为注意力加权，但未充分探索文本和语音在不同情感类别上的可靠性差异。

6. **被试多样性**：300 名大学生被试集中在特定年龄段和教育水平，结论推广到其他群体需谨慎。

## 复现指南

### 环境准备

```bash
# 1. 克隆仓库
git clone <repo-url>
cd emotion-pet

# 2. 创建虚拟环境
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
.venv\Scripts\activate     # Windows

# 3. 安装依赖
pip install -r requirements.txt

# 4. 设置环境变量
cp .env.example .env
# 编辑 .env 设置 DEVICE=cpu（无 GPU 时）
```

### 数据准备

```bash
# 下载并预处理数据
python scripts/download_data.py --dataset all --target ./data/raw

# 或按 docs/dataset.md 手动下载各数据集，放入 data/raw/ 对应子目录
```

### 训练

```bash
# 一键训练（推荐）
bash scripts/run_all.sh

# 或分步执行：

# 1) 训练情感识别模型
python -m emotion_recognition.train --config config.yaml --epochs 20

# 2) 训练 DQN 智能体
python -m rl_agent.train --config config.yaml --episodes 1000

# 3) 评估
python -m emotion_recognition.evaluate --checkpoint checkpoints/emotion_best.pt
```

### 查看训练日志

```bash
# TensorBoard 可视化
tensorboard --logdir logs/

# 浏览器打开 http://localhost:6006
```

### 随机种子

项目全局随机种子为 42（见 config.yaml）。如需更换：

```yaml
# config.yaml
seed: 123  # 改为其他整数
```

PyTorch、NumPy、Python random 的种子均由此值统一设置，确保实验可复现。
