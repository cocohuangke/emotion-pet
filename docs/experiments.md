> 采用反频率 class-weighted loss 平衡。数据按 8:1:1 分层划分，早停 patience=5。

**多模态融合消融（同一 checkpoint，`--modality` 切换）**：

| 配置 | Accuracy | F1-macro | 对比单模态提升 |
|------|----------|----------|----------------|
| 仅文本 (BERT) | 0.2473 | 0.0854 | — |
| 仅语音 (CNN+LSTM) | 0.0773 | 0.0341 | — |
| 文本 + 语音 (Fusion) | **0.5018** | **0.3042** | +0.25 / +0.42 |

### 分析要点

- 对比单模态与多模态的性能差异，验证融合的必要性
- 分析各类情感的识别难度（sad/fear 通常更难区分）
- 可视化混淆矩阵，找出易混淆的情感对
- 对比不同融合策略（早期融合 vs 晚期融合 vs 注意力融合）

### 已得结论（MELD 全量训练）

- **融合显著有效**：fusion 0.5018 远超文本单模态 0.2473、语音单模态 0.0773，
  验证多模态融合的必要性。
- **文本是主导模态**：BERT 文本特征贡献了融合的大部分判别力。
- **语音分支退化（待改进）**：CNN+LSTM 单模态 acc 0.0773 低于随机基线
  （7 类 ≈ 0.14），几乎将所有样本预测为 sad/neutral。可能原因：MFCC 特征区分力弱、
  MELD 短语音（<3 秒）时序模式有限、语音分类头在 fusion 训练中被边缘化。
  改进方向：换 wav2vec2/HuBERT 预训练语音特征、加辅助损失强制语音分支学习。
- **难识别类别**：fear/disgust 的 F1 仅 0.04（测试集各仅 36 条，训练集各约 350 条，
  是 MELD 天然少数类）；neutral/surprise/happy 识别较好。

## 实验二：DQN 行为决策

### 设置

| 超参数 | 值 |
|--------|-----|
| 状态维度 | 12 (emotion 7 one-hot + history 3 + time 2) |
| 动作数 | 5 (comfort / encourage / distract / listen / accompany) |
| 网络结构 | 3 层全连接 [64, 64] |
| 学习率 | 1e-3 |
| 折扣因子 γ | 0.95 |
| ε 起始值 | 1.0 |
| ε 终止值 | 0.05 |
| ε 衰减 | 0.995 / episode |
| 经验回放容量 | 10000 |
| Mini-batch size | 64 |
| 目标网络更新频率 | 10 episodes |
| 训练回合数 | 1000 |

### 初步训练结果

> 以下为 **初步验证** 结果：40 episodes / max 20 steps per episode，
> 用于验证 DQN 训练管线与 reward 收敛趋势，**非最终策略**。
> 完整 1000 episodes 训练待 GPU 环境补充。

| 指标 | 值 |
|------|-----|
| Episodes | 40 |
| 总耗时 | 50.1s (CUDA) |
| 初始 avg reward (前 10) | 0.808 |
| 末期 avg reward (后 10) | 0.732 |
| 全程 avg reward | 1.002 |
| 最小 reward | -1.795 |
| 最大 reward | 3.157 |
| 末期 avg loss | 0.0546 |
| 最终 ε | 0.818 |
| Buffer 大小 | 800 |

**训练曲线（每 10 episodes 滚动平均 reward）**：

```
Episode  10 | avg10 = 0.808 | eps = 0.951 | loss = 0.0600
Episode  20 | avg10 = 0.939 | eps = 0.905 | loss = 0.0547
Episode  30 | avg10 = 1.530 | eps = 0.860 | loss = 0.0549
Episode  40 | avg10 = 0.732 | eps = 0.818 | loss = 0.0546
```

> **分析**: loss 从 0.060 降至 0.055，TD 误差收敛；reward 在 episode 30
> 达到峰值 1.530 后回落，可能因 ε 仍较高（0.818）导致探索性动作引入
> 方差。完整 1000 episodes 训练后 ε 将降至 0.05，预期 avg reward 稳定
> 在 2.0+。

## 已知局限

1. **数据集语言偏差**：训练集为 MELD（英文，老友记），中文语音识别准确率预期低于英文。跨语言泛化存在上限。

2. **实验室环境 vs 真实场景**：公开数据集的语音/文本在噪声、语速、口语化程度上与大学生真实使用场景有差距。

3. **DQN 状态空间简化**：当前状态表示未包含对话历史语义、用户长期偏好等深层信息，可能限制策略优化上限。

4. **用户测试周期**：3 个月的用户测试虽能观察短期效果，但难以评估长期黏性和心理健康持续改善。

5. **单模态融合权重**：当前融合策略为注意力加权，但未充分探索文本和语音在不同情感类别上的可靠性差异。

6. **被试多样性**：300 名大学生被试集中在特定年龄段和教育水平，结论推广到其他群体需谨慎。

## 复现指南

### 环境准备

```bash
# 1. 克隆仓库
git clone https://github.com/cocohuangke/emotion-pet.git
cd emotion-pet

# 2. 创建虚拟环境
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
.venv\Scripts\activate     # Windows

# 3. 安装依赖
pip install -r requirements.txt

# 4. 设置环境变量
cp .env.example .env
# 编辑 .env 设置 DEVICE=cpu（无 GPU 时）
```

### 数据准备

```bash
# 下载并预处理数据
python scripts/download_data.py --dataset all --target ./data/raw

# 或按 docs/dataset.md 手动下载各数据集，放入 data/raw/ 对应子目录
```

### 训练

```bash
# 一键训练（推荐）
bash scripts/run_all.sh

# 或分步执行：

# 1) 训练情感识别模型（--use-pretrained-bert 加载真实 BERT 权重；
#    --freeze-bert 冻结骨干、仅训练分类头，加速收敛并降低显存）
python -m emotion_recognition.train --config config.yaml --epochs 20 --batch_size 32 --lr 1e-4 --use-pretrained-bert --freeze-bert

# 2) 训练 DQN 智能体
python -m rl_agent.train --config config.yaml --episodes 1000

# 3) 评估
python -m emotion_recognition.evaluate --checkpoint checkpoints/best_model.pt
```

### 查看训练日志

```bash
# TensorBoard 可视化
tensorboard --logdir logs/

# 浏览器打开 http://localhost:6006
```

### 随机种子

项目全局随机种子为 42（见 config.yaml）。如需更换：

```yaml
# config.yaml
seed: 123  # 改为其他整数
```

PyTorch、NumPy、Python random 的种子均由此值统一设置，确保实验可复现。
